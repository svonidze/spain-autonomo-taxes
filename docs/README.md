# Documentation

User guidance is in [user/](user/): the accounting workflow, statuses, account
settings, counterparty corrections, exchange rates, and history replay.
Developer guidance is in [development/](development/): frontend development,
localization, privacy, and the repository layout. Operational runbooks live in
[ops/docs/](../ops/docs/), including deployment, provisioning, frontend build,
and disaster recovery. [plans/](plans/) records historical proposals and
implementation decisions; it is not an operating manual.

The repository's shared examples are in [examples/](../examples/) and the
official calendar input is [reference/tax-calendars/2026.json](../reference/tax-calendars/2026.json).
